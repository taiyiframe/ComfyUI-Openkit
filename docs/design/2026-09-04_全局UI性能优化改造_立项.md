## 一、目标

把 Openkit 素材加载器打造成「通用、极简、功能极强」的全局素材加载器：
- 一键用在任何工作流，学习成本最低、理解成本最低；
- 素材数量不设上限，但具备一整套极致易用/简洁/易理解/高性能/高用户体验的**素材编号自动管理机制**；
- 前端个人风格化、UI 体验最优、性能最优、占用资源最低；
- 吸收竞品优点、保留自身优势、避免抄袭，形成自研 UI 风格标准，为统一设计优化其他节点打基础。

## 二、设计要点（已确认）

### 2.1 分层信息架构
工具栏 / Tab 栏 / 卡片网格 / 弹窗 / 底座 五层清晰分区，控件最小 44px 触控区。

### 2.2 素材无上限 + 编号双轨制
- **稳定排序轨**：素材内部稳定序号（增删不改动历史序号）；
- **派生显示号**：按分类动态重算的显示编号，用户只看到派生号、不可编辑；
- 排序用 sort 中值插入 + 局部重算，避免全量 O(n) 重排；
- 关键帧/角色/道具/场景 总顺序在历史基础上保持，切换分类后对新加入/调整图片自动编号。

### 2.3 Lite Design 自研风格
- 中性底 + 琥珀强调（#B08D2E）、6px 圆角、150ms 反馈；
- 落地 DESIGN_TOKENS.md + tokens.css + openkit_ui.js；
- 杜绝抄袭（不复制 Easy / 竞品样式），形成统一风格标准。

### 2.4 性能链路（浏览器渲染 / 内存极致优化）
- 磁盘缓存 → 内存 LRU（≤40 张）→ 虚拟化渲染 → 事件委托 → 细粒度 patch → 重型资源按需回收；
- 素材无上限时只渲染可视区卡片，滚动按需创建/销毁 DOM。

### 2.5 ~~三类素材统一裁剪体系~~（已废弃 2026-09-04，用户决定移除）
- ~~图片/视频/音频批量套用裁剪方案 + 方案预设 + 裁剪后缩略图缓存。~~ 不再实施。
- 保留既有单素材裁剪能力：图片/视频裁剪（归一化矩形）、视频/音频时长剪辑（trim）。

## 三、资产清单（此前已输出给用户）

### 3.1 吸收的新优势（9 条）
调研对象：ComfyUI-Easy-Use / ComfyUI_Local_Image_Gallery / ComfyUI-ImageBatchLoader / batch_image_loader / ComfyUI-Gallery 等（2026-09-05 调研）。
只吸收设计思想，不复制样式（样式见 2.3 Lite Design 原创）。
1. **悬停即时预览** —— batch_image_loader 下拉悬停直接预览图（素材槽位悬停放大预览）。
2. **动态 UI 显隐** —— 根据模式自动显隐控件（按「列表/索引/名称」模式自适应显示对应控件）。
3. **文件夹/路径预设** —— Local_Image_Gallery 路径预设下拉快速访问（素材目录快捷切换）。
4. **多选批量操作** —— Gallery/ImageBatchLoader 的 Ctrl 多选 + 批量删除/下载（图片槽位批量删除）。
5. **拖拽放置反馈** —— 拖拽换位时的高亮/占位反馈（强化现有拖拽排序）。
6. **风格/档案模板管理** —— Easy-Use 的 Fooocus 风格选择器（多段编辑器档案模板预设增强）。
7. **一体化少节点化** —— Easy-Use 整合加载器的思路（素材加载器进一步合并常用操作入口）。
8. **双模式索引** —— 下拉列表 或 直接索引 两种选图方式并存（Tab 索引 + 名称选择）。
9. **整文件夹导入** —— ImageBatchLoader 的 📂 上传整个文件夹（素材批量导入）。

### 3.2 原创优化点（6 条）
1. 素材无上限 + 编号双轨制（稳定排序轨 + 派生显示号，排序用 sort 中值插入 + 局部重算）。
2. Tab 页 = 独立素材集（每段一套完整参考，Tab索引 路由输出指定素材）。
3. 分类自动编号（关键帧→角色→道具→场景，切换分类自动分配该分类首个未用编号）。
4. 性能链路原创实现：窗口化虚拟渲染 + 事件委托 + 懒加载 + rAF 合并尺寸学习 + 重型资源主动释放。
5. H3 六段式提示词自动生成 + 强制禁止 BGM 精准控制（自定义第 7 段）。
6. 多级 Tab 可视化 JSON 编辑器（7 大模块 + 三级嵌套，全程零 JSON 接触）。

### 3.3 保留的自身优秀设计（10 条）
1. 图片槽位顶部标题栏（分类下拉 + 只读自动编号）。
2. 分类下拉 + 只读自动编号机制。
3. 拖拽换位重编号（sort 中值插入 + 局部重算，不 O(n) 全排）。
4. 预设系统（保存 / 加载 / 删除）。
5. Track→Tab 音轨路由（配对 / 独立 / 关闭）。
6. Tab 索引输出（指定素材，不支持「全部素材」）。
7. 多段提示词可视化编辑（多级 Tab，零原始 JSON）。
8. 全插件中英双语一键切换（openkit_i18n.js，localStorage 持久化）。
9. Lite Design 原创 UI 风格（中性底 + 琥珀强调，杜绝抄袭）。
10. 三栏布局（图片 | 音频 | 视频）+ 每栏独立 `+` 按钮。

### 3.4 改掉/去掉的项
**改掉 4 项**：
1. 单一大节点「黑盒」倾向 → 透明可查（每个输入输出/控件均有 tooltip 与说明）。
2. 固定图片数量上限 → 素材无上限。
3. 全量 DOM 渲染 → 窗口化虚拟渲染（只渲染可视区）。
4. 每次变更全量 commit → rAF 合并 + 容器级事件委托。

**去掉 3 项**：
1. 「全部素材」输出（不再支持，只保留 Tab 索引输出）。
2. 三类素材统一批量裁剪体系（2026-09-04 已废弃并回退）。
3. 复制竞品样式（杜绝抄袭，统一 Lite Design 原创标准）。
