## 四、PK 记录（分歧 / 反驳 / 裁决）

### 4.1 关键合并发现：前后端各看一半、拼起来才成立的真阻断

- **后端 S1**：`execution_time.py:173-186` 关闭分支依赖 `event=="executing" and data.node is None`。核对 ComfyUI 0.34.x：结束走 `execution.py:824 execution_success`（异常 `:712`、中断 `:699`），全文件**没有任何一处**发 `executing{node:None}`；唯一 `executing` 在 `:496` 恒带真节点 → **`openkit.exec_end` 结构性永不发出**（per-node 的 `openkit.exec_time` 从 execute 出口直发，是活的）。
- **前端 F2**：`execution_time.js:360 startRaf()`，`stopRaf()/freezeTimer()` 只在 `:404` 收到 `openkit.exec_end` 时调用。
- **合并裁决（三方一致）**：无论后端 patch 成不成功，只要跑在 0.34.x，`exec_end` 都发不出 → 前端 RAF **永久运行、总计时器永久卡死**。前端原结论"patch 失效才泄漏"**说轻了**，修正为"patch 成功也泄漏"，100% 必现。

### 4.2 核心分歧：技术总监"补 E2E 后提交、不重构" vs 前后端"必须重构"

| 技术总监第一轮立场 | 后端/前端反驳（证据） | PK 后裁决 |
|---|---|---|
| 总计时"补验证"即可 | S1 已证事件源找错，`exec_end` 永远发不出；E2E 跑多少次都不可能绿，E2E 只会**证明**它死，不会治好它 | **接受，收回"不重构"** |
| 过 E2E 即可，不重构 | B1：`__init__.py:8` 无条件 import → `execution_time.py:22 import execution`，离线 `test_package_load.py` 直接 `ModuleNotFoundError`，这是合并即回归，E2E 在跑着的 8188 上根本暴露不到 | **接受** |
| 过 E2E 即可，不重构 | S3：`execution_time.py:107→:51-61` 每节点 `torch.cuda.reset_peak_memory_stats()` 洗进程级全局 CUDA 账本；E2E 视觉全绿也测不出这个副作用 | **接受** |
| — | 前端 F1：新节点零 i18n，违反宪法双语硬基线，属"补基建"不是"补验证" | **接受，门槛上调到重构级** |

**裁决结论**：技术总监正式收回"不重构"。共识——**E2E 是重构之后的验收门，不是替代重构的捷径**；不改事件源/不懒加载 import/不删全局清零，E2E 既无必要（必不过）也跑不起来。patch `execution.execute` 落点本身正确、per-node 计时活，故**方向不放弃，重构后提交**。

### 4.3 splitter "无上限"：后端静默截断 × 前端 UI 承诺无上限

- 前端侧：`media_loader.js:16-17` `MAX={picture:Infinity,video:Infinity,audio:Infinity}`，`computeTags` 渲染到 `Video N/Audio N`。
- 后端侧：`media_loader.py:165` 全量解码，`:410-419` `pad(videos,3)/pad(audios,8)` 静默丢第 4 路视频/第 9 路音频。
- **裁决（双方一致升级为严重）**：这是用户可见的静默数据丢失——前端告诉用户存在 Video 4，下游只发 3 端口，空 `None` 与标签编号错位，用户以为接了第 4 路实际拿到 None。四方口径（注释说无 cap / 测试断言无 cap / splitter 偷偷截 / Description 写死 3·8）必须收口。

### 4.4 第三颗雷：权威解释器已坏（技术总监第一轮漏列）

- 后端实测 `venv312\Scripts\python.exe` exit 103，报 `No Python at '"D:\Python312\python.exe'`；技术总监亲自复跑确认：基座 `D:\Python312\python.exe` 已删、`pyvenv.cfg` 显示该 venv 原建在 `D:\ComfyUI_T8`、整体搬迁到 ROB2900 后基座路径从未重建（且路径带多余引号）。
